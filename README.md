# Оценка просматриваемости угодий и обнаружения лося

Инструменты для работы со снимками БВС. По ручной разметке программа рассчитывает долю видимой земли под пологом, сопоставляет наблюдения с лесотаксационными выделами и сравнивает обнаружение животных обычной камерой и тепловизором.

## Установка

Требуются Python 3.10 или новее и графический рабочий стол для ручной разметки. Из каталога программы выполните `python -m pip install -r requirements.txt`. В примерах `flights` содержит папки вылетов, а `stands.gpkg` — двумерные полигоны выделов в EPSG:4326. При нескольких слоях укажите имя через `--layer`.

Контрольный прогон выполнен на Windows с Python 3.12.13.

## Видимость земли

```sh
python tochki_vidimost.py flights/flight01 --grid 7
python privyazka_k_videlam.py --papka flights --taksaciya stands.gpkg
```

Первая команда открывает широкоугольные JPG. В каждой точке нажмите **1**, если видна земля под пологом, **0**, если её закрывает растительность, и **2** для открытого места. После последней точки выберите тип насаждения. Результат сохраняется в `tochki.csv` выбранного вылета. Знаменатель доли видимости включает классы 0 и 1. Если все точки открытые, значение остаётся пустым.

Вторая команда назначает выдел **центру снимка**. Для наклонной съёмки используется горизонтальное смещение по высоте и азимуту камеры. Если азимут отсутствует, расчёт использует координаты БВС. В текущем каталоге появятся `vidimost_po_snimkam.csv` и `vidimost_svodka.csv`. Метка «не лесфонд» в историческом формате CSV означает отсутствие попадания в слой. При неполном покрытии карты по этой метке нельзя судить о типе угодий.

## Выдел для каждой точки сетки

```sh
python grid_to_stands.py flights/flight01/image_W.JPG points.geojson --dem terrain.tif --taksaciya stands.gpkg --focal-px 1500 --height-offset 0 --marks flights/flight01/tochki.csv
```

Программа строит луч через центр каждой ячейки, находит пересечение с цифровой моделью рельефа и записывает точки в GeoJSON для просмотра в ГИС. Подставьте рабочее фокусное расстояние **в пикселях** для разрешения снимка и поправку к абсолютной высоте камеры **в метрах** для системы высот ЦМР. Числа в команде иллюстрируют синтаксис. Нужны исходный широкоугольный снимок DJI с метаданными, практически нулевой крен подвеса и тайл FABDEM в EPSG:4326 с привязкой PixelIsPoint. Расчёт использует центральную проекцию без поправки на дисторсию.

По умолчанию сетка 7 × 7 занимает весь кадр. Укажите те же `--grid` и `--oblast`, что и при разметке. Например, `--oblast T` ограничивает сетку центральной зоной тепловизора H20N. Старый формат CSV хранит последовательность классов, но не границы зоны. Параметр `--marks` добавляет класс исходной точки и проверяет совпадение имени файла и длины разметки. Без него можно рассчитать одну геометрию.

Одна запись GeoJSON соответствует одной точке, нумерация идёт по строкам сверху вниз. Поле `stand_matches` показывает число совпадений. При одном совпадении записываются квартал, выдел и атрибуты насаждения. Флаги `within_10_m` и `within_15_m` помогают отобрать точки у ближайшей найденной границы. Отсутствующие атрибуты таксации остаются пустыми. Для номера квартала используется поле `kv`, для выдела — `taxationun` или `taxationunit`.

## Сверка двух камер

```sh
python poisk_losey.py flights/flight01 --kamera W
python poisk_losey.py flights/flight01 --kamera T
python sverka_losey.py --papka flights --taksaciya stands.gpkg
```

Завершите слепой просмотр обычных снимков W перед открытием тепловизионных T. Левый щелчок ставит отметку, правый убирает её, пробел сохраняет кадр и переходит к следующему. Для группировки по времени сохраняйте исходные имена DJI с датой и временем. Программа объединяет близкие отметки по месту и времени и определяет выдел по средней точке группы. Пороги по умолчанию — 20 м и 60 с. Расчёт рассчитан на съёмку вниз.

Таблица `losi_sverka.csv` содержит группы отметок и признаки видимости каждой камерой. В `losi_svodka.csv` попадают уверенные группы в полосе тепловизора. Доля пропусков обычной камеры рассчитана относительно животных, замеченных хотя бы одной камерой. CSV используют UTF-8 с BOM и точку с запятой. Сводные таблицы перезаписываются при повторном запуске.
